# بوابة إدارة وعرض سياسات الجودة — مستشفى المنصورة الدولي (MIH)
### Hospital Quality Policies & Clinical Bundles Web System

نظام ويب متكامل لإدارة وعرض سياسات الجودة وحزم الرعاية الإكلينيكية بمستشفى المنصورة الدولي، مبني بفلسفة **"السرعة الفائقة وانعدام تكلفة التخزين" (Zero File Storage Architecture)**.

---

## 🌟 أبرز مميزات النظام

1. **تصفح عام وفوري (Public Access):**
   - يفتح الموقع لجميع الأطباء والتمريض والعاملين والزوار مباشرة دون الحاجة لأي تسجيل دخول.
   - بحث شامل فوري في العناوين والأكواد والنص الكامل للسياسات.
   - فلترة لحظية حسب أقسام المستشفى (المعايير الوطنية NSR، مكافحة العدوى IPC، الأدوية MMS، الجودة QPI، السلامة FMS، الطوارئ ER).

2. **لوحة إدارة مؤمنة بحساب Google (Admin via Firebase Auth):**
   - زر "دخول الإدارة" عبر **Google Sign-In**.
   - فحص القائمة البيضاء (**Admin Whitelist**): لا يُسمح بأي إجراء إداري (إضافة، تعديل، حذف، رفع ملفات) إلا للمديرين المعتمدين بإيميلاتهم المحددة.
   - في حال دخول مستخدم غير مصرح له، يتم إبقاؤه في وضع التصفح العام مع إظهار تنبيه لطيف.

3. **قاعدة بيانات Firestore خفيفة جداً (بدون استهلاك مساحة تخزين):**
   - حفظ السياسات كبيانات JSON مهيكلة تتضمن نص الوثيقة (HTML) والشرائح التفاعلية (Slides).
   - سرعة فائقة في استرجاع الوثائق (< 200ms) حتى مع بطء شبكات المستشفيات.

4. **محرك الرفع والتحويل الذكي (Smart Client-Side Parser & AI):**
   - **ملفات Word (`.docx`):** استخراج النص والفقرات والجداول وبناء الشرائح تلقائياً في المتصفح عبر `mammoth.js`.
   - **ملفات PDF والعروض التقديمية (Gemini 2.5 Flash API):**
     - إمكانية تحديد نطاق صفحات محددة (مثل الصفحات 1-10 من ملف الدليل الضخم ذو الـ 320 صفحة).
     - استخراج بالذكاء الاصطناعي بدقة 100% باللغة العربية السليمة وبناء الشرائح تلقائياً بدون أخطاء انعكاس الحروف.
   - **المعاينة والتحرير قبل الحفظ:** محرر تفاعلي مع معاينة حية للوثيقة ومحاكي للشرائح قبل النشر في Firestore.

5. **نظام رفع الصور والمخططات الانسيابية عبر Cloudinary:**
   - رفع مباشر من المتصفح (Unsigned Upload) إلى Cloudinary API.
   - ضغط الصور الصغيرة إلى `WebP` عبر Canvas.
   - إدراج رابط الصورة بنقرة واحدة داخل نص الوثيقة أو داخل الشريحة المحددة.

6. **طريقتان لعرض أي سياسة:**
   - **وضع الوثيقة (Document Mode):** ترويسة رسمية تشبه ورق المستشفى المعتمد مع جداول منسقة وزر للطباعة المباشرة (`window.print()`) المتوافقة مع ورق A4.
   - **وضع العرض التقديمي (Presentation Mode):** عارض شرائح ملء الشاشة (Slide Deck) عالي الجودة يدعم الأسهم والمسطرة واللمس على الموبايل والتابلت لتدريب الأطباء والتمريض.

## ⚙️ إعداد المتغيرات والمفاتيح (Configuration)

في أعلى ملف `js/app.js` (أو من خلال زر **⚙️ الإعدادات** في الشريط العلوي للموقع)، ستجد المتغيرات التالية:

```javascript
// 1. إعدادات Firebase (من لوحة تحكم Firebase Console)
const FIREBASE_CONFIG = {
  apiKey: "YOUR_FIREBASE_API_KEY",
  authDomain: "YOUR_PROJECT.firebaseapp.com",
  projectId: "YOUR_PROJECT_ID",
  storageBucket: "", // غير مستخدم
  messagingSenderId: "1234567890",
  appId: "1:1234567890:web:abcdef"
};

// 2. القائمة البيضاء لإيميلات مديري الجودة المصرح لهم (Google Accounts)
const ADMIN_EMAILS = [
  "admin@mih-quality.gov.eg",
  "quality.mih@gmail.com",
  "your.email@gmail.com" // ضع إيميلك هنا
];

// 3. إعدادات Gemini API (للتحويل الذكي من PDF ونصوص إلى شرائح)
const GEMINI_CONFIG = {
  apiKey: "YOUR_GEMINI_API_KEY", // احصل عليه مجاناً من Google AI Studio
  model: "gemini-2.5-flash"
};

// 4. إعدادات Cloudinary (لرفع الصور والمخططات)
const CLOUDINARY_CONFIG = {
  cloudName: "YOUR_CLOUD_NAME",
  uploadPreset: "YOUR_UNSIGNED_PRESET"
};
```

> **ملاحظة ذكية:** يمكنك إدخال هذه الإعدادات مباشرة من نافذة **⚙️ الإعدادات** في الموقع وسيتم حفظها محلياً في متصفحك دون الحاجة لتعديل الكود برمجياً. وإذا لم تدخل المفاتيح، سيعمل الموقع تلقائياً في **وضع العرض المحلي التجريبي (Local Demo Mode)** بكامل وظائفه!

## 🔒 قواعد أمان Firestore (`firestore.rules`)

تم تصميم قواعد الأمان لتوفير أقصى درجات الحماية مع السماح بالقراءة العامة:
- **القراءة (Read):** متاحة للجميع بدون شروط: `allow read: if true;` لتمكين كافة الأطباء والتمريض من قراءة السياسات.
- **الكتابة والتعديل والحذف (Write/Create/Update/Delete):** مشروطة بالتحقق من إيميل المدير المسجل ومطابقته للقائمة البيضاء أو مجموعة `admins`.
- **التحقق من صحة البيانات:** التأكد من وجود كافة الحقول المطلوبة ومطابقتها للشروط وحدود الأحجام لمنع استنزاف الموارد.

لرفع القواعد إلى Firebase:
```bash
firebase deploy --only firestore:rules
```

## 🚀 كيفية التشغيل

يمكنك تشغيل النظام بأي من الطرق التالية:
1. **فتح مباشر:** فتح ملف `index.html` أو `mih.html` في أي متصفح حديث (Chrome, Edge, Firefox).
2. **عبر Live Server:** فتح المجلد في VS Code والضغط على **Go Live**.
3. **عبر خادم محلي:**
   ```bash
   npx serve .
   ```
