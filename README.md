# بوابة إدارة وعرض سياسات الجودة — مستشفى المنصورة الدولي (MIH)
### Hospital Quality Policies & Clinical Bundles Web System (React Edition)

نظام ويب متكامل لإدارة وعرض سياسات الجودة وحزم الرعاية الإكلينيكية بمستشفى المنصورة الدولي، معاد بناؤه بتقنية **React + Vite + TypeScript + Tailwind CSS** مع الحفاظ على فلسفة **"السرعة الفائقة وانعدام تكلفة التخزين" (Zero File Storage Architecture)**.

---

## 🌟 أبرز مميزات النظام

1. **تصفح عام وفوري (Public Access):**
   - واجهة مستخدم سريعة ومتجاوبة بالكامل باللغة العربية (RTL).
   - بحث شامل فوري في العناوين والأكواد والنص الكامل للسياسات.
   - فلترة لحظية حسب أقسام المستشفى (المعايير الوطنية NSR، مكافحة العدوى IPC، الأدوية MMS، الجودة QPI، السلامة FMS، الطوارئ ER).

2. **لوحة إدارة مؤمنة بحساب Google (Firebase Auth):**
   - تسجيل الدخول الإداري الآمن عبر Google Sign-In المعتمد.
   - التحقق من دور المدير من مجموعة `admins` في Firestore (تُفرض بالقواعد).
   - إبقاء المستخدمين غير المصرح لهم في وضع التصفح العام مع تنبيه لطيف.

3. **قاعدة بيانات Firestore خفيفة وسريعة:**
   - حفظ السياسات كبيانات JSON مهيكلة تتضمن نص الوثيقة (HTML) والشرائح التفاعلية (Slides).
   - دعم التزامن الحي (Real-time snapshots) والتخزين الاحتياطي المحلي في المتصفح.

4. **محرك الرفع والتحويل الذكي (Smart In-Browser & AI Engine):**
   - **ملفات Word (`.docx`):** استخراج النص والفقرات والجداول وبناء الشرائح تلقائياً في المتصفح عبر `mammoth`.
   - **ملفات PDF والعروض التقديمية (Gemini 2.5 Flash API):**
     - إمكانية تحديد نطاق صفحات محددة (مثل الصفحات 1-10 من ملف الدليل ذو الـ 320 صفحة) عبر `pdf-lib`.
     - استخراج بالذكاء الاصطناعي بدقة 100% باللغة العربية السليمة وبناء الشرائح تلقائياً.
   - **المعاينة والتحرير قبل الحفظ:** محرر تفاعلي مع معاينة حية للوثيقة ومحاكي للشرائح قبل النشر.

5. **رفع الصور والمخططات الانسيابية عبر Cloudinary:**
   - رفع مباشر من المتصفح (Unsigned Upload) إلى Cloudinary API.
   - ضغط الصور الصغيرة إلى `WebP` عبر Canvas.
   - إدراج رابط الصورة بنقرة واحدة داخل نص الوثيقة أو داخل شريحة محددة.

6. **وضعان لعرض أي سياسة:**
   - **وضع الوثيقة (Document Mode):** ترويسة رسمية مطابقة لورق المستشفى المعتمد مع جداول منسقة وزر للطباعة المباشرة (`window.print()`) المتوافقة مع ورق A4.
   - **وضع العرض التقديمي (Presentation Mode):** عارض شرائح ملء الشاشة (Slide Deck) عالي الجودة يدعم الأسهم والمسطرة واللمس على الموبايل والتابلت لتدريب الأطباء والتمريض.

7. **حزم الرعاية الإكلينيكية التفاعلية (Clinical Bundles):**
   - متابعة تطبيق قوائم التحقق لخفض عدوى المستشفيات (CLABSI, VAP, CAUTI, SSI, Sepsis).
   - حساب فوري لنسبة الالتزام وتحديث مؤشرات الأداء وحفظ الحالة محلياً.

## 🛠️ البنية التقنية (Tech Stack)

- **Framework:** React 18 & HTML5/ES6 Standalone Mode
- **Bundler:** Vite
- **Language:** TypeScript & JavaScript
- **Styling:** Tailwind CSS (Theme tokens, RTL, Custom Scrollbars, Hospital Print Styles)
- **Database & Auth:** Firebase Firestore & Firebase Authentication
- **Security Rules:** `firestore.rules` بأدوار (editor / admin / superadmin) من مجموعة `admins`
- **Document Parsers:** Mammoth (.docx) & PDF-Lib (.pdf)
- **AI Extraction:** Gemini 2.5 Flash عبر وكيل خادم آمن `api/gemini.ts` (المفتاح على الخادم فقط)
